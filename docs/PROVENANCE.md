# Source attribution and transformation record

**Original authors' code:** [sophiakenney/compare_sdublin](https://github.com/sophiakenney/compare_sdublin).  
**Associated article:** [Genomic evolution of *Salmonella* Dublin in cattle and humans in the United States](https://doi.org/10.1128/aem.00689-25).  
**Original supplemental files:** [Zenodo 15652582](https://zenodo.org/records/15652582).

This repository is an organized reproduction of the original authors' deposited workflow. It does not assert authorship of the original study or claim that a new biological analysis has been completed.

Changes on the `publication-restructure` branch are limited to organizing source files and data, configuring paths, repairing explicitly nonportable command invocations, and adding documentation and an archiving procedure. The original scientific thresholds and the deposited data are intended to remain unchanged; each runnable stage still requires empirical verification before a final archival release.
