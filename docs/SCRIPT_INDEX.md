# Script index — *Salmonella* Dublin comparative genomics

Paths below are relative to the repository root. The original filenames are preserved.

## B1 — Reads and taxonomic QC

| Script | Function and handoff |
| --- | --- |
| [`accessionqc.sh`](../workflow/B1_Reads_QC/accessionqc.sh) | Download SRA FASTQs, compress and summarize raw read QC using FastQC, MultiQC and SeqKit |
| [`trimqc.sh`](../workflow/B1_Reads_QC/trimqc.sh) | Two-pass Trimmomatic adapter/quality processing followed by trimmed-read QC |
| [`classifyreads.sh`](../workflow/B1_Reads_QC/classifyreads.sh) | Kraken2 classification and per-isolate reports |
| [`filterreads.sh`](../workflow/B1_Reads_QC/filterreads.sh) | KrakenTools extraction of Enterobacteriaceae reads (taxonomic ID 543), retaining paired reads |

## B2 — Assembly, assembly QC and typing

| Script | Function and handoff |
| --- | --- |
| [`assembly.sh`](../workflow/B2_Assembly_Typing/assembly.sh) | Assemble filtered paired reads with Unicycler |
| [`assembqc.sh`](../workflow/B2_Assembly_Typing/assembqc.sh) | CheckM and QUAST assembly quality assessment |
| [`seqsero2.sh`](../workflow/B2_Assembly_Typing/seqsero2.sh) | SeqSero2 assembly-based serotype calls and report aggregation |
| [`sistr.sh`](../workflow/B2_Assembly_Typing/sistr.sh) | SISTR serotype/cgMLST calls and report aggregation |
| [`mlst.sh`](../workflow/B2_Assembly_Typing/mlst.sh) | *S. enterica* Achtman MLST scheme calls |

## B3 — Phylogenomics

| Script | Function and handoff |
| --- | --- |
| [`modeltest.sh`](../workflow/B3_Phylogenomics/modeltest.sh) | ModelTest-NG search on Roary's `core_gene_alignment.aln` |
| [`iqtree.sh`](../workflow/B3_Phylogenomics/iqtree.sh) | IQ-TREE ML phylogeny, GTR+I+G4, 1,000 ultrafast bootstrap replicates and BNNI |

## B4 — Genome annotation and pangenome

| Script | Function and handoff |
| --- | --- |
| [`prokka.sh`](../workflow/B4_Pangenome/prokka.sh) | Annotate assembled genomes with Prokka |
| [`combineprokkasummary.sh`](../workflow/B4_Pangenome/combineprokkasummary.sh) | Combine individual Prokka text summaries into a table |
| [`roary.sh`](../workflow/B4_Pangenome/roary.sh) | Roary pangenome construction and MAFFT core-gene alignment |

## B5 — AMR and plasmid annotation

| Script | Function and handoff |
| --- | --- |
| [`amrfinder.sh`](../workflow/B5_AMR_Virulence_Plasmids/amrfinder.sh) | AMRFinderPlus annotation using Prokka protein/GFF and assembly sequence |
| [`abricate.sh`](../workflow/B5_AMR_Virulence_Plasmids/abricate.sh) | ABRicate PlasmidFinder calls and summary. The original VFDB summary is supplied under `data/abricate/`; it is not generated by this script |

## B6 — Downstream publication analyses in R

| Script | Publication output |
| --- | --- |
| [`plotmeta.R`](../workflow/B6_Comparative_Analyses/plotmeta.R) | Metadata characterization and Figure 1 |
| [`readqc.R`](../workflow/B6_Comparative_Analyses/readqc.R) | Read-quality summaries and supplementary tables |
| [`assembqc.R`](../workflow/B6_Comparative_Analyses/assembqc.R) | Assembly-quality and typing summaries |
| [`abricate.R`](../workflow/B6_Comparative_Analyses/abricate.R) | Plasmid/virulence comparisons and Tables 1 and 4 |
| [`amrfinder.R`](../workflow/B6_Comparative_Analyses/amrfinder.R) | AMR comparisons, Tables 2–3 and Figure 2 |
| [`pangenome.R`](../workflow/B6_Comparative_Analyses/pangenome.R) | Pangenome comparisons, Table 5 and Figure 3A–C |
| [`anno.R`](../workflow/B6_Comparative_Analyses/anno.R) | Functional/COG annotations and Figure 3D |
| [`snp.R`](../workflow/B6_Comparative_Analyses/snp.R) | Genetic/SNP distances and Figure 4B–D; tree visualization was done externally with iTOL |

The phylogeny and pangenome are produced from the Roary core-gene alignment. This project does **not** claim a Snippy/Gubbins stage simply because those tools are present in the separate SEN workflow.

All original environment YAML filenames are in [`environments/`](../environments): `abricate.yaml`, `amrfinder.yaml`, `bioinfo.yaml`, `checkm.yaml`, `iqtree.yaml`, `mlst.yaml`, `prokka.yaml`, `roary.yaml`, `seqsero2.yaml`, `sistr.yaml`, and `unicycler.yaml`. Build strings originate from the authors' environment exports; consult [docs/EXECUTION.md](EXECUTION.md) about portability.
